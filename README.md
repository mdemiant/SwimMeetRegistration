# SwimMeetRegistration
Swim Meet Registration is a program designed to simulate and help understand the registration process for a swimmer participating in a swimming competition. The program collects basic information such as the swimmer’s name, age, selected events, and times. Based on this information, it determines the swimmer’s competition category and the day they will compete in each event and how at the end they appear in the final program after all the swimmers have registrated.

This project is interesting because registering for a swimming competition involves several steps that need to be organized correctly. By simulating this process, the program provides a simple way to understand how information is collected, processed, and used to generate a final registration.

The main purpose of the project is to learn and understand a real-world process through algorithms and programming, while applying basic Python concepts such as variables, conditional statements, loops, lists, and functions.
